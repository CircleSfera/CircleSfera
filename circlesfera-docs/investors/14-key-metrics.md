## What we will measure

Metrics align with product principles and business lines. We measure behaviour we can explain to the user, not vanity counts alone.

### Acquisition

| Metric | Definition |
| --- | --- |
| Signups | New accounts created |
| Verified users | Email verified (and identity where required) |
| Invite conversion | Invites sent → accounts created |
| Creators who post | Profiles with ≥1 public post in period |

### Activation

| Metric | Definition |
| --- | --- |
| Profile complete | Avatar, username, bio filled |
| First post | Time to first published content |
| First follow | Social graph entry |
| First conversation | Messaging activation |
| First creation in studio | Studio session completed |

### Retention

| Metric | Definition |
| --- | --- |
| D1 / D7 / D30 | Return rates |
| DAU / MAU | Active user ratio |
| Post frequency | Content creation per active creator |

### Monetization

| Metric | Definition |
| --- | --- |
| Platform plan conversion | % of MAU on paid plan |
| Creators with Connect | Onboarded to Stripe Express |
| Creators with ≥1 payment | Earned in period |
| GMV | Gross merchandise value through Connect |
| Platform fee revenue | 20% of GMV + promotion payments + plan MRR |
| ARPU | Average revenue per user |
| MRR | Monthly recurring from platform plans |

### Trust and safety

| Metric | Definition |
| --- | --- |
| Reports per 1k DAU | Report volume |
| Appeal rate | Appeals / moderation actions |
| Time to first response | Trust desk SLA |
| Repeat violations | Accounts with multiple actions |

Trust metrics protect the brand defined in [00-principles-and-values.md](./00-principles-and-values.md). They are not optimised away for engagement.
