## Scope of this document

This is not a corporate social responsibility essay. It lists **shipped expressions** of CircleSfera's product principles on moderation (principle 4) and data handling (principle 5). Aspirations not in the product are omitted.

---

## Safety and moderation (principle 4)

| Control | Status |
| --- | --- |
| User reporting | Shipped — report content and accounts |
| Moderation actions | Shipped — warn, suspend, restore |
| Author notification | Shipped — on hide/limit where appropriate |
| Appeals | Shipped — user-facing in Settings |
| Appeal outcomes | Shipped — notification on decision |
| Staff trust desk | Shipped — separate admin application, MFA |
| Anti-shadowban policy | Shipped — no silent reach reduction as management tool |
| Age requirement | Shipped — 16+ on registration, client and server |

When something is limited, the platform aims to tell the user what happened, why, under which rule, and how to contest it.

---

## Data and privacy (principle 5)

| Control | Status |
| --- | --- |
| Purpose limitation | Documented in product compliance materials |
| Data export | Shipped — GDPR export includes stories, likes, notifications, settings, appeals, collections, transactions |
| Account deletion | Shipped — grace period; login restores during window; hard-delete cron |
| Cookie consent | Shipped — telemetry gated |
| Message encryption | Shipped — encrypted at rest; key rotation supported |
| Device signals | Shipped — hashed clustering for abuse; not used to cut reach |
| IP retention | Admin and export only; documented retention |

The platform must justify what it collects, why, for how long, and on what basis. Uses that significantly affect experience must remain explainable.

## Identity and money

| Control | Status |
| --- | --- |
| Identity verification before commerce | Shipped |
| Plan badge ≠ KYC | Shipped — verified badge tied to identity, not subscription tier |
| Published platform fee | Shipped — 20% on creator commerce |

Dark-pattern monetization is explicitly rejected in product principles.
