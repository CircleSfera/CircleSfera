# Use of funds

**Internal — not for cold email.**  
Base scenario: **€2.5M seed** · Target range **€2.5–5M** · August 2026

Raise policy: finish the commercial product, new creation tools, hire engineering / product / trust. **Creators are not paid to post.**

---

## €2.5M base allocation (100%)

| Category | € | % | What it buys |
| --- | ---: | ---: | --- |
| Engineering (full stack, mobile, platform) | 875,000 | 35% | Native apps, warehouse, promotions scale, web + API |
| Product and design | 375,000 | 15% | Next creation tools, mobile UX, research |
| Trust and Safety | 300,000 | 12% | Trust lead + ops; moderation capacity before open |
| Infrastructure and tools | 200,000 | 8% | Cloud/analytics upgrade, CI, security, SaaS |
| Founder salary (below market until hire) | 150,000 | 6% | 18-month runway |
| Legal, accounting, compliance | 100,000 | 4% | Incorporation, contracts, counsel |
| GTM reserve (phase 3 only) | 125,000 | 5% | Earned paid/organic after conversion proof |
| Buffer / contingency | 375,000 | 15% | Hiring slippage, infra spikes, 2 extra months runway |
| **Total** | **2,500,000** | **100%** | |
